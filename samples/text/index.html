How €42,000 becomes €16,100 to live on

Savings available €42,000, minus €600 deciding costs, minus €11,000 moving costs, minus €2,300 tied-up deposits, minus €8,000 emergency reserve, minus €4,000 return fund, leaves €16,100 for monthly shortfalls.

This calculation uses the €16,100 left after the deciding costs, moving costs, tied-up deposits, emergency reserve and return fund have been set aside. It does not use the full €42,000 in savings.
